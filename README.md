This repository contains my hands-on networking labs created while preparing for the Cisco Certified Network Associate (CCNA) certification.

I use Cisco Packet Tracer to practice networking concepts, build and configure network topologies, and improve my troubleshooting skills.

I'm documenting my labs here to track my learning progress, gain practical experience, and keep a record of the networking concepts I've explored.

This repository will continue to grow as I learn new topics and gain more hands-on experience throughout my CCNA preparation.
